문제
정수를 하나 입력받아, 입력된 값이 양수이면 해당 값과 “Positive number”를 출력하는 프로그램을 작성하시오.
입력
첫째 줄에 정수 하나가 주어진다.
출력
첫째 줄에 Input value : 와 입력받은 정수를 이어서 출력한다.
입력받은 정수가 양수이면 둘째 줄에 Positive number를 출력한다.
예제
입력 9
출력 Input value : 9
Positive number
