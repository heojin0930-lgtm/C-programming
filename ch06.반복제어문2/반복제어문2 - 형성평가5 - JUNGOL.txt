문제
10개의 정수를 입력받아 입력받은 수들 중 짝수의 개수와 홀수의 개수를 각각 구하여 출력하는 프로그램을 작성하시오.
입력
첫째 줄에 정수 10개가 공백으로 구분되어 주어진다.
출력
첫째 줄에 even : 과 짝수의 개수를 이어서 출력한다.
둘째 줄에 odd : 와 홀수의 개수를 이어서 출력한다.
예제
입력 10 20 30 55 66 77 88 99 100 15
출력 even : 6
odd : 4

#include <stdio.h>
int main(void) {
int a, i;
int even = 0;
int odd = 0;
for (i = 1; i <= 10; i++) {
scanf("%d", &a);
if (a % 2 == 0) {
even++;
}
else {
odd++;
}
}
printf("even : %d\n", even);
printf("odd : %d\n", odd);
return 0;
}
