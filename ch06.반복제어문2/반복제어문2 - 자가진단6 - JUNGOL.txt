문제
10 이하의 과목수 n을 입력받은 후 n개 과목의 점수를 입력받아서 평균을 구하여 출력하고 평균이 80점 이상이면 "pass", 아니면 "fail"이라고 출력하는 프로그램을 작성하시오.
평균은 반올림하여 소수 첫째자리까지 출력한다.
입력
첫째 줄과 둘째 줄에 10 이하의 과목수 n가 주어진다.
출력
첫째 줄부터 2개의 줄에 걸쳐 서 평균을 구하여 출력하고 평균이 80점 이상이면 "pass", 아니면 "fail"이라고 출력하는 평균은 반올림하여 소수 첫째자리까지 출력한다.를 순서대로 출력한다. 결과는 반올림하여 소수점 아래 첫째 자리까지 출력한다.
예제
입력 4
75 80 85 90
출력 avg : 82.5
pass

#include <stdio.h>
int main(void) {
int n, a;
int i;
int sum = 0;
double ave;
scanf("%d", &n);
for (i = 1; i <= n; i++) {
scanf("%d", &a);
sum += a;
}
ave = (double)sum / n;
printf("%.1f\n", ave);
if (ave >= 80) {
printf("pass");
}
else {
printf("fail");
}
return 0;
}
