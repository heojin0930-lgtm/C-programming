문제
다음 프로그램을 디버깅 모드로 실행하고, 각 표시된 줄에서 커서가 있을 때 변수 x의 값을 확인하여 각 값들을 수정하여 제출하시오.
(입력값은 75를 사용한다.)
입력
첫째 줄에 정수 75가 주어진다.
출력
디버깅 과정에서 문제에 표시된 각 줄에 도달했을 때의 변수 x 값을 순서대로 출력한다.
예제
입력 75
출력 직접 실행해서 확인
<기본 코드>
#include <iostream>
using namespace std;
int main() {
int x = 50;         // 초기값
cin >> x;            // [A] 이 줄에 커서가 있을 때 x 값 확인
if (x >= 80) {
x += 10;        // [B] 이 줄에 커서가 있을 때 x 값 확인
} else {
x -= 5;         // [B] 이 줄에 커서가 있을 때 x 값 확인
}
x--;                // [C] 이 줄에 커서가 있을 때 x 값 확인
int A = 0;          // [A]에서 확인한 값으로 수정
int B = 0;          // [B]에서 확인한 값으로 수정 (두 군데중 하나만 해당)
int C = 0;          // [C]에서 확인한 값으로 수정
cout << A << " " << B << " " << C << '\n';
return 0;
}
