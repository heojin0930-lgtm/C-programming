문제
다음 프로그램을 디버깅 모드로 실행하고, 표시된 줄에서 커서가 있을 때 변수 x의 값을 확인하여 확인된 값들의 합이 출력되도록 sum의 값을 수정하여 제출하시오
입력
입력은 주어지지 않는다.
출력
첫째 줄에 9을 출력한다.
예제
출력 9
<기본 코드>
#include <iostream>
using namespace std;
int main() {
int x = 2;      // 초기값
while (x < 5) {
x++;         // [A] 이 줄에 커서가 있을 때 x 값 확인
}
int sum = 0;      // [A] 줄에서 확인한 x값의 합으로 수정
cout << sum << '\n';
return 0;
}
