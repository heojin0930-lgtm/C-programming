문제
1. Input
2. Output
3. Delete
4. Finish
Enter number:
위와 같은 메뉴를 출력하고 숫자를 입력받아 선택한 번호에 해당하는 다음의 메시지 를 출력하는 작업을 반복하시오.
1 : "You selected Input."
2 : "You selected Output."
3 : "You selected Delete."
4 : "You selected Finish."를 출력한 후 프로그램을 종료한다.
1~4 이외의 수가 입력되면 "Wrong input."을 출력한다.
입력
메뉴를 선택하는 정수가 반복해서 주어진다.
단, 각 입력 전에 메뉴와 다음과 같은 메시지를 출력한다.
1. Input
2. Output
3. Delete
4. Finish
Enter number: (입력)
출력
1, 2, 3, 4 중 하나의 정수가 입력되면 각각 순서대로
You selected Input.,
You selected Output.,
You selected Delete.,
You selected Finish.중 하나를 출력한다.
1부터 4까지가 아닌 수가 입력되면 Wrong input.을 출력한다.
단, 해당 출력의 앞 뒤로 한 줄의 공백이 출력되어야 한다.

#include <stdio.h>
int main(void) {
int a;
for (;;) {
printf("1. Input\n");
printf("2. Output\n");
printf("3. Delete\n");
printf("4. Finish\n");
printf("Enter number: ");
scanf("%d", &a);
printf("\n");
switch (a) {
case 1:
printf("You selected Input.\n");
break;
case 2:
printf("You selected Output.\n");
break;
case 3:
printf("You selected Delete.\n");
break;
case 4:
printf("You selected Finish.\n");
break;
default:
printf("Wrong input.\n");
break;
}
printf("\n");
if (a == 4) {
break;
}
}
return 0;
}
