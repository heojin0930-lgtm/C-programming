문제
0부터 100까지의 점수를 계속 입력받다가 범위를 벗어나는 수가 입력되면 그 이전까지 입력된 자료의 합계와 평균을 출력하는 프로그램을 작성하시오.
(평균은 반올림하여 소수 첫째자리까지 출력한다.)
입력
값이 순서대로 주어진다. 문제에서 설명한 종료 조건이 만족되면 입력이 종료된다.
출력
첫째 줄부터 2개의 줄에 걸쳐 0부터 100까지의 점수를 계속 입력받다가 범위를 벗어나는 수가 입력되면 그 이전까지 입력된 자료의 합계와 평균을 출력하는 (평균은 반올림하여 소수 첫째자리까지 출력한다.)를 순서대로 출력한다. 결과는 반올림하여 소수점 아래 첫째 자리까지 출력한다.
예제
입력 55 100 48 36 0 101
출력 sum : 239
avg : 47.8

#include <stdio.h>
int main(void) {
int a;
int sum = 0;
int count = 0;
double avg = 0;
for (;;) {
scanf("%d", &a);
if (a < 0 || a > 100) {
break;
}
sum += a;
count++;
}
avg = (double)sum / count;
printf("sum : %d\n", sum);
printf("avg : %.1f\n", avg);
return 0;
}
